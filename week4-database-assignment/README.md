# Week 4 Database Assignment

## Advanced SQL Queries and Aggregations

This assignment demonstrates the use of SQL aggregation functions and clauses including:

- SUM()
- AVG()
- MAX()
- GROUP BY
- ORDER BY
- LIMIT

## Questions

### Question 1
Calculate the total payment amount for each payment date and display the latest 5 dates.

### Question 2
Calculate the average credit limit for each customer.

### Question 3
Calculate the total price of products ordered.

### Question 4
Find the highest payment amount for each check number.
