# Week 5 Database Assignment

## Database Indexing and Optimization

This assignment focuses on database indexing, user accounts, privileges, security, and password management using SQL.

## Learning Objectives

1. Add and manage indexes in database tables.
2. Create database users with specific host restrictions.
3. Grant privileges to database users.
4. Change user passwords.
5. Practice database security and access control.

## Assignment Questions

### Question 1

Drop an index named `IdxPhone` from the `customers` table.

### Question 2

Create a user named `bob` with a password and restrict the user to the `localhost` hostname.

### Question 3

Grant the `INSERT` privilege to user `bob` on the `salesDB` database.

### Question 4

Change the password for user `bob`.

- `answers.sql` - Contains the SQL answers for all four questions.
